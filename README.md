# sd-forge-advanced-stylebox
Extension for SD Forge Neo, which creates new UI with expanded Style box with lot of QoL features compared to regular style selector box. 

How styles affect the image are often affected by other loras, alternative models or just AIs mood.
I frequently find it nesessary to tweak styles to get the result I want, but to do that I must either apply the style to the prompt box or permanently modify the style. 
With this extension can select Styles and edit them on fly, without cluttering the the prompt box or losing the original style. 

The basic behaviour is same as the default style dropdown, so this supports {prompt} syntax.
